# Descripción

Este repositorio de GIT HUB contiene las prácticas de la asignatura optativa de Bioinformática.


# Organización

El repositorio "bioinfo" se estructura de la siguiente manera:

 - README.md: archivo el cual se encuentra leyendo ahora mismo y que contiene información general del repositorio.
 - results/: carpeta que contiene los resultados de las prácticas realizadas a lo largo del cuatrimestre.
 - doc/: referencias bibliográficas
 - data/: datos de entrada
 
 
Dentro de la carpeta "results" se encuentran varias subcarpetas, cuyo nombre es una fecha. Cada fecha corresponde a la práctica realizada ese día.

En cada una de estas carpetas se incluye: 

 - El guión de la practica en formato .qmd
 - El documento del quión ccompilado en formato .html
 - Resultados obtenidos si los hubiera
